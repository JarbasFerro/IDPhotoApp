# Profile research — Schengen visa

**Status:** Researched (L19-013); search-based official evidence accepted (ADR-051).
**Date:** 2026-11-11
**Profile:** `eu.schengen-visa`, print. One profile for all Schengen consulates. Each consulate may add details, so Help says to check the consulate's own page.

| Rule | Value | Evidence |
|---|---|---|
| Standard | ICAO Doc 9303 Part 1 (6th edition); non-compliant photos are not accepted | [Visa Code handbook, C(2024) 4319](https://home-affairs.ec.europa.eu/document/download/1d79f44d-49ba-4847-951e-129f924b1051_en) |
| Size | 35–40 mm wide (EU ICAO guide). **35 × 45 mm** is the common print size in EEAS consular guides | [EU ICAO photo guidelines](https://home-affairs.ec.europa.eu/document/download/5bb16566-c8c2-4afb-b038-530f488cb72a_en?filename=icao_photograph_guidelines_en.pdf), [EEAS Schengen guide](https://www.eeas.europa.eu/sites/default/files/2026/documents/Schengen%20Visa%20Guide%20EN.pdf) |
| Face | 70–80 % of the photo height | EU ICAO guide; [Regulation 810/2009](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=celex:32009R0810) |
| Recency | No more than 6 months old | EU ICAO guide |
| Background | White in EEAS guides; ICAO allows plain light | EEAS |
| Live photo | When the applicant gives fingerprints in person, a photo taken that day can satisfy the requirement | Visa Code handbook |

**Calipic values:** 35 × 45 mm; face 70–80 % (about 32–36 mm); white replacement colour. Help says that some consulates take the photo during the visa appointment.
